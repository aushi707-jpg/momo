Publishing (GitHub)

Publish saves your changes to the menu’s GitHub repository. The token is stored encrypted with your admin password and kept only on this device. It never leaves this browser except to talk to GitHub. On a new phone or computer, paste the token once.

After changing the password, the old one may keep working for a few minutes while the site updates.
